# READ ME

Code associated with the paper

```
Z. Zheng, C. C. Darabundit, and G. Scavone, "Physical model of the Chinese yehu for sound synthesis," In. Proc. 29th Int. Conf. Digital Audio Effects (DAFx26), Cambridge, MA, USA, 1-4 Sept. 2026. 
```

Code requires Matlab and CMake. 

## QUICK START
Gesture examples from the paper can be generated by running

```
examples/exGestures.m
```

Phrase example from the paper can be generated by running 
```
examples/exPhrases.m
```

By default, the code runs using Matlab code. The C++ implementation can be run after building the correct `.mex` executable. 

## CMAKE AND MEX
The CPP implementation depends on the Eigen library which will be automatically installed. 

To build the correct `.mex` executable run
```
cd cpp
cmake -S . -B release -D CMAKE_BUILD_TYPE=Release
cmake --build release
```
Then switch the computation flag correspondingly in the example code. 


Code has been tested on the following processors:

Apple M1, MacBook Pro 2020

CMake commands to compile on Unix and Windows have been included but are untested. The Matlab directory might need to be manually specified for Windows builds!
